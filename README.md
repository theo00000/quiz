# React Quiz App

Aplikasi kuis berbasis React yang dibuat untuk memenuhi technical test magang.

Aplikasi menggunakan Open Trivia Database (OpenTDB) sebagai sumber soal dan memiliki fitur login, timer, progress quiz, hasil pengerjaan, serta mekanisme resume menggunakan localStorage.

---

# 1. Project Overview

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Vite
- React Router DOM
- Open Trivia Database API
